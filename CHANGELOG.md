# Changelog

## 1.3.0 — Portal bookmarks

- Added world- and server-scoped portal bookmarks with separate Overworld and Nether coordinates.
- Added a configurable bookmark menu for saving the current position or a locked target, navigation, renaming, and confirmed deletion.
- Added localized bookmark names, locations, and destination-aware HUD arrival messages.
- Added persistent-storage regression checks.

## 1.2.1 — Minecraft 26.2

- Updated Minecraft, Fabric Loader, Fabric API, Fabric Loom, and the Gradle wrapper for Minecraft 26.2.
- Added a Gradle build check for Nether and Overworld coordinate conversions, including negative coordinates.
- Added a GitHub Actions build for pull requests and pushes to `main`.
